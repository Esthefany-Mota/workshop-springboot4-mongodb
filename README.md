# Workshop MongoDB 🚀

Projeto de estudo desenvolvido durante minha formação em desenvolvimento backend, com foco na integração de uma aplicação **Java com MongoDB** utilizando **Spring Boot**.

O projeto foi desenvolvido como prática dos conceitos apresentados em um curso, com o objetivo de compreender como uma aplicação backend pode se conectar e trabalhar com um banco de dados NoSQL.

## 🎯 Objetivo

O principal objetivo do projeto foi aprender, na prática, como realizar a integração entre uma aplicação desenvolvida em **Java e Spring Boot** e um banco de dados **MongoDB**.

Durante o desenvolvimento, foram explorados conceitos de persistência e manipulação de documentos, além da criação de operações para trabalhar com os dados armazenados no banco.

## 🛠️ Tecnologias utilizadas

* **Java**
* **Spring Boot**
* **Spring Data MongoDB**
* **MongoDB**
* **Maven**
* **Git e GitHub**

## ⚙️ O que foi desenvolvido

A aplicação trabalha com informações de usuários armazenadas no MongoDB e permite praticar operações de persistência e manipulação dos dados.

Entre os principais conceitos praticados estão:

* Conexão da aplicação com o MongoDB;
* Configuração do banco de dados;
* Mapeamento de documentos utilizando `@Document`;
* Persistência de dados;
* Consultas ao banco;
* Operações de criação, atualização e exclusão;
* Desenvolvimento de endpoints para interação com os dados.

## 📚 O que foi aprendido

O projeto permitiu compreender, na prática, como integrar uma aplicação **Spring Boot** a um banco de dados **NoSQL**, além de aprofundar os conhecimentos sobre o funcionamento e a estrutura do MongoDB.

Também foram consolidados conceitos de **Spring Data MongoDB, persistência de dados, mapeamento de documentos e desenvolvimento de APIs**, contribuindo para minha formação na área de desenvolvimento backend.

Por ser um projeto de estudo, seu principal resultado foi a consolidação dos conceitos e a experiência prática de trabalhar com uma tecnologia de banco de dados diferente das soluções relacionais.

## 📖 Contexto do projeto

Este projeto foi desenvolvido como parte de um processo de aprendizagem baseado em curso, sendo utilizado como prática para consolidar os conhecimentos apresentados sobre **Spring Boot e MongoDB**.
